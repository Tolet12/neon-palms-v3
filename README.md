NEON PALMS v2 is an original open-world crime game set in Palmera Bay, a sun-soaked coastal city of neon strips, palm-lined streets and a working beach. You play a courier taking five hotter and hotter story jobs — checkpoint runs, a hot package, cash drops, a getaway and a harbor finale — while a 0–5 star wanted system brings chasing police, roadblocks and busts, and a reputation ladder raises your payouts. Drive detailed cars with damage and smoke, dodge lane-following traffic, scatter pedestrians, and free-roam for cash pickups between jobs, all rendered in Three.js with a live minimap HUD.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
